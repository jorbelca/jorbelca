### Freelance workflow demos
These prototypes use synthetic data and are not production deployments.

- **Email triage for a law office** · [Demo 1](https://github.com/jorbelca/portfolio-freelance/tree/main/1) — Classifies incoming emails against a review rubric, records the result for audit, and sends ambiguous cases to a person. Built with n8n, OpenRouter and PostgreSQL; evaluated on 28 labeled sample emails.
- **Document Q&A with citations** · [Demo 2](https://github.com/jorbelca/portfolio-freelance/tree/main/1) — Uses retrieval-augmented generation (RAG) and pgvector to answer questions from a document collection, with citations back to the source text. Evaluated with 12 sample questions.
- **Property-management incident triage** · [Demo 3](https://github.com/jorbelca/portfolio-freelance/tree/main/2) — Classifies emailed incidents, retrieves relevant rules, logs the classification and review route in PostgreSQL, and escalates unclear cases to a manager. The demo includes community-level isolation checks and was evaluated on 45 labeled incidents plus 12 retrieval questions.
- **Invoice extraction and validation** · [Demo 4](https://github.com/jorbelca/portfolio-freelance/tree/main/4) — Extracts fields from invoice PDFs with Python and LangGraph, then checks tax IDs, dates, totals and duplicates with deterministic rules. Incomplete or inconsistent invoices enter a review queue; a small dashboard summarizes reasons and amounts held. Exercised with 30 synthetic invoices.
